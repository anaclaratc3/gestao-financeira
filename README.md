# Controle de Finanças Pessoais

Aplicação em desenvolvimento para gerenciamento de finanças pessoais, permitindo o acompanhamento de receitas, despesas, categorias e saldo mensal de forma simples e visual.

## Funcionalidades Previstas

- **Gerenciamento de Transações:** Cadastro e listagem de entradas e saídas.
- **Categorização:** Organização de gastos por categorias (ex: Alimentação, Lazer, Moradia).
- **Dashboard:** Resumo visual de saldo atual e total de receitas/despesas.
- **Autenticação:** Acesso seguro por usuário.

## Tecnologias

- **Frontend:** Next.js com Tailwind CSS
- **Backend:** Node.js
- **Banco de Dados:** PostgreSQL
